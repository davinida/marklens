## 문서 상태 규칙

교수 제출용 학기 문서에서는 다음 상태만 사용합니다.

| 상태 | 의미 |
|---|---|
| `기준선 확보 / 학기 검증 예정` | 현재 구현·검증 기록이 있으며 지정 주차에 재현·분석·시연할 기준선 |
| `계획` | 미래 작업이며 완료형 문장으로 제출하면 안 됨 |
| `진행` | 일부 산출물이 존재하며 완료·잔여 범위를 함께 기록 |
| `완료` | 코드 또는 문서 산출물과 Git 근거가 존재 |
| `검증완료` | 실행 날짜·환경·명령·결과까지 증빙 대장에 기록 |
| `차단` | API, 데이터, 승인 등 선행조건 때문에 진행할 수 없음 |
| `보류` | 근거 또는 우선순위 부족으로 의도적으로 제외 |

현재 기준선은 실제 수행일을 유지한 채 9~10월 보고서의 주차별 수행·검증 항목으로
관리합니다. 재현·분석·시연은 실제로 수행한 뒤에만 `검증완료`로 바꿉니다. 신규 작업은
처음에는 모두 `계획`이며, 제출 시점에
[주장·증빙 매핑표](course/2026-2/99_MarkLens_주장_증빙_매핑표.md)에 근거가 추가된
항목만 `완료` 또는 `검증완료`로 바꿉니다.
