## 프론트-8 / X4 상품 견련성 — 가장 가벼움

```python
def goods_similarity(codes_a: set[str], codes_b: set[str]) -> float:
    """유사군 코드 집합의 자카드 계수. 0.0~1.0.
    ※ 유사군코드는 근사 기준 — 도소매업 등 일부는 코드가 같아도 개별 판단,
      '비고 유사'가 존재한다. (최종 보고서에 한계로 명시 예정)"""
    if not codes_a or not codes_b:
        return 0.0
    return len(codes_a & codes_b) / len(codes_a | codes_b)
```
변환표(프론트-2)의 1:N 구조를 그대로 사용. 위 주석(근사 기준)은 규약상 **반드시 포함**.

## 프론트-9 / E+F. 통합 모델 + 등급 재보정 — 방학 후반~2학기 초

**선행**: 다빈-1(라벨 표) + 다빈-2(X1) + 프론트-7(X3) + 프론트-8(X4)

**절차**
1. 라벨 표의 각 사례에 4축 점수 산출 — 이미지·유사군은 표의 번호로 공보 API 조회(그래서 번호가 필수)
2. `scikit-learn LogisticRegression` — 4축 → 0~100% 위험 확률. 데이터 적으면(수백 건) **로지스틱 회귀 유지, 신경망 금지**
3. 평가: k-fold 교차검증, 정확도, ROC-AUC, 과적합 확인
4. **가중치 해석**: β 부호·크기가 판례 원칙("호칭 > 외관")과 맞는지 대조 — 발표의 핵심 스토리
5. **★ 단독 임계값 안전장치**: 표장 축(X1·X2·X3) 하나라도 매우 높으면(수치는 정답 데이터 분포 보고 결정, 예: 0.9↑) 모델 결과와 무관하게 최소 '검토 권장' 이상. — **2026-07-07 검증에서 완전 동일 로고가 REVIEW로 강등되는 실측 사례가 나왔으므로 이 안전장치는 설계 확정 사항으로 승격 권장**
6. **★ X4 역할 정의**: X4는 표장 유사도를 증폭/억제하는 조정자. 단, 표장이 매우 유사한데 상품만 다르면 위험도를 0으로 내리지 말고 "표장 유사·상품 상이" **참고 경고**(저명상표 무임승차 가능성) — 프론트 경고 자리 준비됨
7. **F 재보정**: 현 0.75/0.55/0.45는 임시값(시연 9장에서 역산). 새 위험도 %에 맞춰 4단계 경계 재설정 + 격차 A 조건을 강등 조건에서 보조 신호로 변경 검토 + **회귀 테스트 추가**: "완전 동일 이미지 → 최상위 등급" 케이스 고정
