## 사용 목적

이 폴더는 4주 단위 진행 보고를 빠르게 준비하기 위한 학기 정본입니다. 1~8주차에는
현재 구현된 핵심 기능을 수업 프로젝트 기준선으로 정리해 재현·분석·시연·보고하고,
9주차부터 벡터 그래픽·손글씨·사람 평가의 신규 연구를 진행합니다.

보고서의 주차는 **학기 중 수행·재검증·분석·제출 활동일**을 나타냅니다. 완료 항목은
commit, 실행일과 artifact 근거를 함께 기록합니다.

미래 작업을 이미 완료한 것처럼 제출하지 않습니다. 대신 각 보고서에 연구 질문,
기술 설계, 평가 지표, 완료 기준과 증빙 위치를 미리 작성해 두어 실제 실행 후 수치와
화면만 갱신할 수 있게 구성했습니다.

## 벡터와 손글씨 범위

`벡터`는 두 의미를 분리합니다.

1. OpenCLIP 512차원 임베딩과 FAISS 검색 벡터는 현재 기준선에서 구현했습니다.
2. SVG·PDF·EPS 같은 벡터 그래픽 파일 업로드는 현재 지원하지 않습니다. 현재 사용자
   업로드 형식은 PNG·JPEG·WebP뿐입니다.

9~12주차에는 SVG v1만 벡터 그래픽 실험 대상으로 삼습니다. SVG 원본을 브라우저에 직접
노출하거나 그대로 임베딩하지 않고, 외부 참조·스크립트·과도한 복잡도를 차단한 뒤
고정 버전 렌더러로 canonical PNG 또는 WebP를 생성해 기존 검색 경로에 연결합니다.
PDF는 단일 페이지 표장 feasibility까지만 검토하고 EPS·AI·CDR은 범위에서 제외합니다.

손글씨·캘리그래피는 래스터 이미지라 현재 검색 요청 자체는 가능하지만 전용 정확도
근거가 없습니다. OCR을 주 경로로 되살리지 않고, 사용자가 상표명을 직접 입력하는
현재 계약을 유지하면서 손글씨형 워드마크의 **시각 검색 강건성**을 별도 표본으로
측정합니다. 사람 라벨과 gate가 준비되기 전 fine-tuning은 하지 않습니다.

## 제출 전 20분 갱신 절차

1. [증빙 매핑표](99_MarkLens_주장_증빙_매핑표.md)에 기준 증거일과 학기 실행일을 기록합니다.
2. `기준선 확보 / 학기 검증 예정`은 주차 활동을 실행한 뒤 `검증완료`로 갱신합니다.
3. 신규 `계획` 행은 증거가 있는 경우에만 `완료` 또는 `검증완료`로 바꿉니다.
4. `제출 전 입력`과 `제출 전 실측` 문자열을 검색해 모두 채웁니다.
5. 수치가 이전 보고서와 달라졌다면 데이터 generation과 기준일을 함께 씁니다.
6. 화면 캡처에는 비밀키, 로컬 절대경로, KIPRIS 임시 URL이 보이지 않는지 확인합니다.
7. 법적 등록 가능성·침해 확률·전체 정확도처럼 측정하지 않은 표현을 제거합니다.
