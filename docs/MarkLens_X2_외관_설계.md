# MarkLens X2 외관 — 현재 구현 요약과 심결 이미지 쌍 벤치마크 v0

기준일 2026-10-08 · 상태: **v0 기준선 측정 완료(변형 실험 전)** · 브랜치 `feat/x2-benchmark`

X2(외관)는 1학기에 OpenCLIP 임베딩 + FAISS 코사인 검색으로 구현돼 현재 서비스(`POST /search`)에
쓰이고 있지만, 그 점수가 심판원의 외관 판단과 얼마나 맞는지는 잰 적이 없었다. 이 문서는 (1) 현재
X2 구현을 요약하고, (2) 심결문 PDF에 내장된 양쪽 표장 이미지로 만든 벤치마크의 정의·추출 방법·
커버리지, (3) v0 결과와 한계를 적는다. 수치는 모두 2026-10-08 실측이다. 데이터(`ml/data/trials/`)는
저장소에 넣지 않는다.

## 1. 현재 X2 구현(1학기 → 현재 서비스)

| 항목 | 내용 | 코드 |
|---|---|---|
| 모델 | OpenCLIP `ViT-B-32`, pretrained `laion2b_s34b_b79k`, CPU 추론 | `ml/src/contracts.py`, `ml/src/embedding.py` |
| 임베딩 | 512차원 float32, L2 정규화. 계약 `openclip-image-v2` | `encode_image()` |
| 전처리 계약(기본) | `clip-center-crop-v1`: EXIF 회전 보정 → 알파는 흰 배경에 합성 → RGB(최소 32px, 최대 4096px, 빈·균일 이미지 거부: 채널 범위 ≥ 4, 표준편차 ≥ 1) → OpenCLIP validation transform(짧은 변 224 리사이즈 + 중앙 crop + 정규화) | `ml/src/preprocess.py` `prepare_model_views()` |
| 전처리 계약(대안) | `global-letterbox-dual-bg-v1`: 224 정사각 레터박스(crop 없음), 알파가 있으면 흰·검 배경 두 view 임베딩을 평균 후 재정규화. 2026-08 paired 비교에서 legacy 와 유의한 차이가 없어 **채택하지 않음**(`ml/evaluation/README.md`) | 같은 파일 |
| 코사인 | FAISS `IndexFlatIP`(inner product) — 정규화 벡터의 내적 = 코사인. `build_index()`·`search()`가 벡터 정규화·metric 을 검증한다 | `ml/src/search.py` |
| 서비스 | `run_search()`: 질의 임베딩 → top-k 검색 → 메타 결합 → `score_results()`(top-1 코사인의 단조 임계값으로 4단계 상태) | `backend/src/core/engine.py`, `ml/src/scoring.py` |

1학기 관찰(설계결정기록 §5): 무관한 로고 사이에도 코사인 0.43~0.59 의 베이스라인이 있어 절대값보다
격차가 신호다. 이번 벤치마크는 그 절대값이 심결의 유사/비유사를 가르는지를 직접 잰 것이다.

## 2. 벤치마크 정의

- **질문**: 특허심판원이 유사/비유사로 결론 낸 실제 표장 쌍에서, 현재 X2 코사인이 그 결론을 가르는가.
- **데이터**: `ml/data/trials/labels.csv`(심결례 843건·1,024행) 중 LLM 이중 라벨(pass a·b)이 **일치하고
  둘 다 유사·비유사**인 350행(320건). 제외·불일치 행은 뺀다. 라벨은 심결의 **최종 결론**이다(§6 참고).
- **쌍**: 행마다 (이 사건 출원·등록상표 `this`, 상대 표장). 상대는 거절결정불복·무효면 선등록상표
  `prior_N`(행의 `상표B_번호` ↔ 색인 등록번호로 매칭, 없으면 순번), 권리범위확인이면 확인대상표장
  `target`. 양쪽 이미지가 있는 행만 쌍이 된다.
- **점수**: `ml/src/embedding.py` 의 `encode_image`(전처리 계약 포함)와 `ml/src/search.py` 의
  `build_index`·`search` 를 그대로 import 해 쌍마다 FAISS inner product 를 읽는다 — 서비스와 같은
  경로이며 별도 구현은 없다. 임베딩은 `ml/data/trials/x2_cache_v0.npz`(파일 sha256 키, 모델·전처리
  계약이 다르면 폐기)에 저장해 변형 실험에서 재사용한다.
- **지표**: ROC AUC(Mann–Whitney 순위, 동점 0.5), 유사·비유사 점수 분포(평균·중앙값·사분위), 정확도가
  최대인 임계값과 그 정확도, 분리도 = 유사 Q1 − 비유사 Q3(양수면 사분위 범위가 겹치지 않음), 기준선 =
  라벨을 섞은 AUC(200회, 평균·5~95%).
- **부분집합**: (a) 전체 (b) 판단축에 '외관' 포함 (c) 상표유형 도형·결합-도형요부 (d) 문자 (e) 연결
  신뢰도 high. **(b)·(c)가 X2 의 공정한 시험대다** — 문자상표 쌍은 호칭·관념으로 갈린 사건이라 글자
  이미지의 코사인이 결론과 맞을 이유가 없고, (a)는 그런 쌍이 절반 넘게 섞여 있다.
- 상표유형은 `상표유형_확정`(사람·LLM 라벨), 없으면 `상표유형_추정`(정규식)을 쓰고 출처를 적는다.

## 3. 이미지 추출·연결(`ml/scripts/trials_extract_images.py`)

`get_image_rects`)의 bbox 를 읽어 읽기 순서(쪽, y, x)로 늘어놓고, 각 이미지를 표장 제목에 연결한다.

`ml/venv/bin/python ml/scripts/x2_benchmark.py` → `ml/data/trials/x2_benchmark_v0.json`, `x2_hist_v0.png`.

| 부분집합 | n (유사/비유사) | AUC | 섞은 라벨 AUC(5~95%) | 정확도 최대 임계값 → 정확도 | 유사 중앙값 | 비유사 중앙값 | 분리도 |

읽는 법과 해석:

- **전체(a) 0.51** — 라벨을 섞은 기준선(0.50, 5~95% 0.45~0.56)과 구별되지 않는다. 임계값 0.218 의
  "정확도 0.615" 는 유사가 59% 라 거의 모두 유사로 찍은 값이다.
- **외관축(b) 0.62** — 기준선 범위(0.40~0.59) 바깥이라 신호는 있지만 약하다. 유사 중앙값 0.59 vs
  비유사 0.54. 임계값 0.845 의 정확도 0.73 은 비유사가 71% 라 "전부 비유사"(0.71)와 거의 같다 —
  임계값으로 쓸 수 없다.
- **도형(c) 0.50** — n 34 로 기준선 범위가 0.33~0.69 까지 벌어져 결론을 내릴 수 없다. 표본 확대가 먼저다.
- **문자(d) 0.56** — 글자 이미지끼리의 전역 코사인이 결론과 거의 무관함을 확인(예상대로).
- 분리도는 모든 부분집합에서 음수 — 유사의 하위 25% 와 비유사의 상위 25% 가 넓게 겹친다
  (히스토그램 `x2_hist_v0.png`: 두 분포가 0.3~0.7 에 겹쳐 있다).
- **결론**: 현재 X2(중앙 crop + CLIP 전역 임베딩의 코사인)는 심결의 외관 판단을 재현하지 못한다.
  이 표가 전처리·crop·마스킹 변형 실험의 **기준선**이며, 변형은 같은 쌍·같은 지표로 (b)·(c)에서 비교한다.

## 6. 한계

- **문자상표 이미지 없음**: 구성이 글자로만 적힌 표장은 합성하지 않아 쌍에 없다(18행). 반대로 글자를
  이미지로 넣은 문서가 많아 쌍의 54%(155)가 문자상표다 — (a)는 X2 의 시험대가 아니다.
- **연결 오류 가능성**: 규칙 기반 연결이다. QA 30쌍 표본 세 번이 모두 맞았지만 전수 확인은 아니고,
  low 2쌍과 순번 매칭 6쌍은 틀릴 수 있다. 쌍 파일의 `연결신뢰도`·`매칭` 열로 걸러 쓴다.
- **실사용 사진**: 권리범위확인의 확인대상표장은 40% 가 상품·간판·포장·화면 캡처 사진으로 추정된다.
  표장 자체가 아니라 사용 장면과 비교하므로 X2 에 불리하고, 판례의 "표장 대비" 와도 다르다.
- **이격적 관찰 미반영**: 판례는 시간·장소를 달리하는 이격적 관찰과 요부 관찰로 외관을 본다. 코사인은
  두 이미지를 나란히 놓은 전역 픽셀 유사로, 요부(지배적 부분)만 떼어 보지 않는다.
- **라벨은 최종 결론**: 판단축이 '상품' 뿐인 24쌍은 표장을 대비하지 않은 사건이고, "표장 유사·상품
  비유사" 메모가 붙은 비유사 6쌍은 외관이 유사해도 비유사로 적혀 있다. (b)는 이들을 자연히 제외한다.
  판단축이 비어 있는 7쌍(권리범위확인의 축 미기재)도 (b)에 들지 않는다.
- **소형 이미지 제외**: 40px 규칙으로 40행이 빠진다(가는 문자 표장). 32px 면 +20쌍.
- **한 표장 한 이미지**: 입체상표의 사시도·정면도 등 여러 view(2024100003331)는 가장 큰 하나만 쓴다.
- **해상도**: 심결문 이미지는 대부분 100~300px 의 JPEG/PNG 로, 서비스 입력(사용자 업로드)보다 작다.
- **표본**: 유사 170/비유사 116, 권리범위확인 160 으로 종류가 치우쳤고 도형 쌍은 34뿐이다. 라벨은
  LLM 이중 라벨(사람 검증 진행 중)이다.
