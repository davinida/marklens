## 2. 마일스톤

> 주차는 2026-07-07(월) 시작 기준. 2학기 개강 ≈ 9월 1주로 가정.
> 원칙: **다빈-1(정답 데이터)은 방학 내내 상시 병행** — 다른 모든 것의 병목이므로 마일스톤에 넣지 않고 매주 진행량을 단톡으로 공유한다.

### M0 — 기반선 (완료, ~7/7)
외관 축 + 백엔드 + 프론트 1차 연동까지 **엔드투엔드로 동작하는 제품 스켈레톤** 확보.
- 완료 판정: 로고 업로드 → 결과 3층 화면까지 브라우저에서 동작 ✅ (2026-07-07 검증)
- 남은 정리: `frontend/` 커밋(브랜치→PR), 중복 클론 `marklens/` 제거, 검증 세션 발견 버그 수정(백엔드-0, 가이드 참조)

### M1 — 착수 주간 (7/7 ~ 7/19, 2주)
서로 독립인 "즉시 가능" 작업을 전원이 동시에 시작한다.
