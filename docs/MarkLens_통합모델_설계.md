## 1. 목적

네 축의 점수 X1(호칭)·X2(외관)·X3(관념)·X4(상품 견련성, 각 0~1)를 합쳐 **출처 혼동 위험도 p ∈ [0, 1]** 과 등급을 낸다. 지금 서비스는 X2 단독 4상태(`grade.status_code`)에 X1·X3 후보를 참고 섹션으로 덧붙이는 구조이며, 통합 모델이 이를 대체한다. 가중치는 사람이 정하지 않고 심결례 정답 데이터(§4)로 학습한다. 결과는 참고 정보이며 법적 판단이 아니라는 경계(README)는 그대로 둔다.

## 3. 모델 구조

- **로지스틱 회귀** p = σ(w·f + b). 입력 벡터 f:
  - 축 점수 X1, X2, X3, X4 (각 0~1, 결측이면 0)
  - 상표 유형 지시변수 T ∈ {문자만, 도형만, 결합-요부문자, 결합-요부도형} (one-hot)
  - 결측 지시변수 m1 = ¬`has_pronunciation`, m3 = ¬`has_meaning`, m4 = ¬`has_goods`
  - 교호작용 X1×T(문자), X2×T(도형), X3×`has_meaning`
- **기대 계수(학습 결과의 검증 기준)**: 문자 유형에서 X1 계수 최대, 도형 유형에서 X2 계수 최대, 결합-요부문자에서 X1·X3 ≥ X2, 결합-요부도형에서 X2 최대. 어긋나면 모델보다 라벨·유형 판정을 먼저 의심한다.
- **결측 축 마스킹**: 발음·관념·유사군이 없는 축은 점수 0 + 지시변수 1로 넣어 "정보 없음"을 "비유사"와 구분한다(X1 §8, X3 §7, X4 §1의 결측 규약과 같다).
- **단독 임계값**: 어느 한 축이 축별 임계값(§4에서 정답 데이터로 결정)을 넘으면 등급을 최소 "검토 권장"으로 올린다(97후3050 후단). 자동 "위험"으로 올리지는 않는다(전단 — 전체관찰).
- **X4의 역할**: 지정상품이 비유사(자카드 0, 제35류 도소매업 개별 판단은 제외)면 상표법 34조 1항 7호의 "동일·유사 상품" 요건이 빠지므로 위험도를 낮춘다. 다만 표장이 매우 유사하면 "표장 유사·상품 상이" 참고 경고는 남긴다(X4 §2).
- **범위 밖**: 인지도 조항(상표법 34조 1항 9·11·12·13호 — 주지·저명·부정한 목적)은 다루지 않는다. 정답 데이터에서도 3등급(유사 판단 없음)으로 제외한다.

X2는 벤치마크 이미지 쌍 306행(X2 설계 §7), X1·X3는 확보한 상표명으로 계산할 수 있다.
- **목표**: 2차 배치(`fetch_queue.csv` 1,071건 중 10월 예산 안에서) → 큐레이션 → 유사·비유사 각 100쌍 안팎의 200쌍, 11월 중순.
- **학습·검증**: 심판 종류(거절결정불복·무효·권리범위확인)별 층화 5-fold 교차검증. 지표는 AUC·정확도와 §3의 계수 부호·크기 검증. 200쌍에 계수 8~14개는 빠듯하므로 L2 정규화를 쓰고 교호작용은 근거가 확인된 것만 남긴다.
- **등급 임계 재보정**: p를 4단계(STRONG/POSSIBLE/WEAK/NO_CLOSE 명칭 유지 여부는 §6)로 나누는 구간을 라벨 분포에서 정한다.
- **단독 임계값 결정**: 라벨된 쌍에서 "그 축 하나만으로 유사로 판정된" 사례의 축 점수 최솟값 분포로 축별 임계값을 정한다.

## 5. 한계

- 거래실정(2011다97065)과 인지도 조항은 범위 밖이다. 저명상표 무임승차 사례는 모델이 과소평가한다.
- 심판까지 간 사건만 라벨이 되므로 다툼이 있는 경계 사례가 과대표집된다(쉬운 유사·비유사는 적다).
- 라벨 수가 적다(목표 200쌍). 계수가 많아지면 과적합하므로 교호작용을 늘리지 않는다.
- 선등록(인용) 상표의 명칭은 2026-10-08 보강으로 350행 중 320행에 있고(§4), 이미지는 X2 벤치마크 306쌍(X2 설계 §7). 남은 30행(확인대상표장 22·번호 없는 기타 7·상표명 없는 도형 표장 1)은 X1·X3 결측으로 다룬다. 지정상품 유사군은 양쪽이 있는 행이 187뿐이라 X4 결측도 많다(고시 43류 단독 명칭·영문 지정상품 미대응).
- 서비스의 X3 하한 0.55와 X2 4상태 임계값은 모두 교정 전 잠정값이다.
- 2026-10-08 축별 벤치마크(§4-1): 어느 축도 단독 AUC 0.6 을 넘지 못하고 정밀도 0.9 임계값이 없다. 식별력 없는 공통 부분(GATE/GATE)을 분리관찰이 1.0 으로 올리는 문제는 식별력 필터(다빈-3)의 `extra_generic` 없이는 풀리지 않는다.
- 2026-10-09 재측정(§4-2): 명칭 LLM 추출로 X1 0.60·X2 철자 외관축 0.73 까지 올랐지만 식별력 v0 는 +0.01 안이다 — 전체 대비 규칙과 X1 포함 규칙이 "약한 토큰 하나뿐인 이름" 쌍을 그대로 두기 때문(식별력 설계 §4·§6). 쉬운 음성을 더한 현실 분포에서는 이름 축이 0.8~0.9 라, 심결례 AUC 는 경계 사례 변별력으로 따로 읽는다.
