# MarkLens 통합 모델 설계 초안 — 판례가 정한 구조

- 기준일: 2026-10-01 (초안 v0.1) · 상태: **설계 초안 — 구현·학습 전** · 입력 축: X1 `ml/src/axes/x1_phonetic.py`(v1.5) · X2 `ml/src/scoring.py`(CLIP 시각 유사도) · X3 `ml/src/axes/x3_semantic.py`(v1.3) · X4 `ml/src/axes/x4_goods.py`(v1) · 정답 데이터: `backend/scripts/trials_collect.py`(브랜치 `feat/trials-collect`, develop 병합 전)
- 관련 문서: [X1 설계](MarkLens_X1_호칭유사도_설계.md) §8 통합 인터페이스, [X3 설계](MarkLens_X3_관념유사도_설계.md) §7, [X4 설계](MarkLens_X4_상품견련성_설계.md) §2 근사 한계, README "다축 모델과 축 함수".

## 1. 목적

네 축의 점수 X1(호칭)·X2(외관)·X3(관념)·X4(상품 견련성, 각 0~1)를 합쳐 **출처 혼동 위험도 p ∈ [0, 1]** 과 등급을 낸다. 지금 서비스는 X2 단독 4상태(`grade.status_code`)에 X1·X3 후보를 참고 섹션으로 덧붙이는 구조이며, 통합 모델이 이를 대체한다. 가중치는 사람이 정하지 않고 심결례 정답 데이터(§4)로 학습한다. 결과는 참고 정보이며 법적 판단이 아니라는 경계(README)는 그대로 둔다.

## 2. 판례가 정한 구조

| 상황 | 원칙 | 근거 | 모델 반영 |
|---|---|---|---|
| 총론 | 외관·호칭·관념을 객관적·전체적·이격적으로 관찰한다. 어느 하나가 유사해도 전체로 보아 혼동을 피할 수 있으면 비유사이고, 반대로 다른 부분이 있어도 호칭·외관이 유사해 혼동하기 쉬우면 유사다 | 대법원 2000. 2. 25. 선고 97후3050 | 결합은 학습된 가중합(전단). 한 축의 단독 임계값 초과는 자동 "위험"이 아니라 최소 "검토 권장"(후단) |
| 문자상표 | 호칭의 유사 여부가 가장 중요한 요소 | 97후3050 | 유형 지시변수(문자) × X1 교호작용. 학습 결과에서 X1 계수가 가장 커야 한다 |
| 도형상표 | 외관이 지배적 인상 | 대법원 2013. 3. 28. 선고 2010다58261(2011후1548) | 유형 지시변수(도형) × X2 교호작용. X2 계수가 가장 커야 한다 |
| 결합상표 | 전체관찰이 원칙이고, 요부가 있으면 요부로 대비한다 | 대법원 2018. 6. 15. 선고 2016후1109, 2018. 9. 13. 선고 2017후2932 | 결합-요부문자 / 결합-요부도형 두 유형으로 나눠 조건부 가중치 |
| 관념 | 국내 수요자의 인식 수준이 기준 — 쉽게 아는 뜻만 관념으로 본다 | 대법원 2005. 9. 30. 선고 2004후2628 | X3 게이트 `has_meaning`(사전 단어만 비교)의 근거. 관념이 없으면 결측 축으로 마스킹 |
| 거래실정 | 수요자 특성·상품 속성·거래 방법을 종합해 판단한다 | 대법원 2013. 6. 27. 선고 2011다97065 | 범위 밖(§5). 모델은 표장·상품 축만 본다 |

## 3. 모델 구조

- **로지스틱 회귀** p = σ(w·f + b). 입력 벡터 f:
  - 축 점수 X1, X2, X3, X4 (각 0~1, 결측이면 0)
  - 상표 유형 지시변수 T ∈ {문자만, 도형만, 결합-요부문자, 결합-요부도형} (one-hot)
  - 결측 지시변수 m1 = ¬`has_pronunciation`, m3 = ¬`has_meaning`, m4 = ¬`has_goods`
  - 교호작용 X1×T(문자), X2×T(도형), X3×`has_meaning`
- **기대 계수(학습 결과의 검증 기준)**: 문자 유형에서 X1 계수 최대, 도형 유형에서 X2 계수 최대, 결합-요부문자에서 X1·X3 ≥ X2, 결합-요부도형에서 X2 최대. 어긋나면 모델보다 라벨·유형 판정을 먼저 의심한다.
- **결측 축 마스킹**: 발음·관념·유사군이 없는 축은 점수 0 + 지시변수 1로 넣어 "정보 없음"을 "비유사"와 구분한다(X1 §8, X3 §7, X4 §1의 결측 규약과 같다).
- **단독 임계값**: 어느 한 축이 축별 임계값(§4에서 정답 데이터로 결정)을 넘으면 등급을 최소 "검토 권장"으로 올린다(97후3050 후단). 자동 "위험"으로 올리지는 않는다(전단 — 전체관찰).
- **X4의 역할**: 지정상품이 비유사(자카드 0, 제35류 도소매업 개별 판단은 제외)면 상표법 34조 1항 7호의 "동일·유사 상품" 요건이 빠지므로 위험도를 낮춘다. 다만 표장이 매우 유사하면 "표장 유사·상품 상이" 참고 경고는 남긴다(X4 §2).
- **범위 밖**: 인지도 조항(상표법 34조 1항 9·11·12·13호 — 주지·저명·부정한 목적)은 다루지 않는다. 정답 데이터에서도 3등급(유사 판단 없음)으로 제외한다.

## 4. 정답 데이터·학습·검증

- **라벨(쌍 단위)**: 유사/비유사(심결 결론), 결정축(심결이 든 이유: 호칭·외관·관념·상품 중 복수), 상표 유형(문자·도형·결합, 요부). 자동 선별의 1등급 후보(34조 1항 7호로만 결론, 인지도 언급 없음)를 사람이 확정한다.
- **현황(2026-09-30, `feat/trials-collect`)**: 심판사항 API 목록 129개월 42,474건, 표본 393건(시범 20 + 1차 373), `labels.csv` 438행, 자동 1등급 84건(1차 373건 중 77건). 사람 라벨링 전, 이달 호출 924/950. 선등록 상표명·이미지가 아직 없어 X2·X3 점수를 계산할 수 없다(§5).
- **목표**: 2차 배치(`fetch_queue.csv` 1,071건 중 10월 예산 안에서) → 큐레이션 → 유사·비유사 각 100쌍 안팎의 200쌍, 11월 중순.
- **학습·검증**: 심판 종류(거절결정불복·무효·권리범위확인)별 층화 5-fold 교차검증. 지표는 AUC·정확도와 §3의 계수 부호·크기 검증. 200쌍에 계수 8~14개는 빠듯하므로 L2 정규화를 쓰고 교호작용은 근거가 확인된 것만 남긴다.
- **등급 임계 재보정**: p를 4단계(STRONG/POSSIBLE/WEAK/NO_CLOSE 명칭 유지 여부는 §6)로 나누는 구간을 라벨 분포에서 정한다.
- **단독 임계값 결정**: 라벨된 쌍에서 "그 축 하나만으로 유사로 판정된" 사례의 축 점수 최솟값 분포로 축별 임계값을 정한다.

## 5. 한계

- 거래실정(2011다97065)과 인지도 조항은 범위 밖이다. 저명상표 무임승차 사례는 모델이 과소평가한다.
- 심판까지 간 사건만 라벨이 되므로 다툼이 있는 경계 사례가 과대표집된다(쉬운 유사·비유사는 적다).
- 라벨 수가 적다(목표 200쌍). 계수가 많아지면 과적합하므로 교호작용을 늘리지 않는다.
- 선등록(인용) 상표의 명칭·이미지가 정답 데이터에 없다 — 출원속보 API 등록번호 검색으로 건당 1~2회 보강해야 X2·X3를 계산할 수 있다.
- 서비스의 X3 하한 0.55와 X2 4상태 임계값은 모두 교정 전 잠정값이다.

## 6. 결정 대기

- 등급 4단계 매핑: p 구간과 기존 `status_code` 명칭 유지 여부.
- 축별 단독 임계값(§4 방법으로 산출 후 사람이 확정).
- 상표 유형 판정 방법: 비엔나코드 유무·문자 유무로 자동 판정할지, 요부(식별력 필터, 다빈-3) 연계 시점.
- 정답 데이터 라벨 도구·담당·일정, 2차 배치 일 상한.
